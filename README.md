# Deeptest Analytics

Static company site. Each section is its own page. No build step.

## Run locally

From this folder:

```bash
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

## Pages

- Home — `index.html`
- What we build — `what.html`
- Who it is for — `who.html`
- Contact — `contact.html`
